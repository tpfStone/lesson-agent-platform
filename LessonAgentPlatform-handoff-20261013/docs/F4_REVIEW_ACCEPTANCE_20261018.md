# 协同共析修订与回看验收（2026-10-18）

本次完成三角形面积教案测试提出的五项修改。第四项按最终确认实现只读回看，不实现撤销已保存的选择。

## 修复结果

1. 删除章节导航底部解释内部划分规则的备注。
2. 新建议使用原始节点文本和稳定地址，格内换行不再经过表格投影转义再写回。字面量反斜杠和竖线继续按原文保留。
3. 表格修改定位到单元格；一条建议可以修改多格并一次性保存。识别到整行塞入单格、定位过期或范围无法对应时，整条建议不应用，也不允许强制追加到表后。独立新增内容仍可正常补充。
4. 增加“回看上一单元”、已完成章节目录和“返回当前单元”。回看显示原建议、选择记录和当前修订稿，使用“已完成 · 回看中”标识，不显示修改操作。整轮完成及会话结束后也有回看入口。
5. 新建议按节点分别修改多个段落、列表项或单元格；旧建议的完整连续段落也可安全替换。P5 的问题来自建议跨越三个段落，和是否在文件尾部无关。

## 定位依据与边界

- 本地原始导入结构与用户 DOCX 表格一致。实际旧建议将整行投影作为教师活动单格的替换稿，包含可见的 `\n` 和列分隔符，导致 P2 的错位。
- 原来定位失败后允许“作为补充采纳”，可以产生 P4 的表后重复内容。已复现并封堵这一条路径；没有另一台电脑的会话记录，不能断言其当次操作经过完全相同。
- 对方导出不是完成本次修复的前提；只有追溯其那一次的具体生成结果和操作顺序时才需要。
- schema 1.1 的旧整行投影只有在行标识、列数、定位范围和转义往返均一致时才分格写入。schema 1.0 的整行转义无法区分真实路径，保守拒绝重建；单格原始文本仍可修改。
- 历史已保存正文与决定不自动重写。对已被污染的历史修订稿，可从原始教案开启新的共析进行验证。
- 新节点编辑必须使用支持该能力的修订策略；旧 append-only 策略快照不会被绕过。
