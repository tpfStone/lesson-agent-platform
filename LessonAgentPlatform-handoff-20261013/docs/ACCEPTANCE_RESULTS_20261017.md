- **F2 局部规则（Q2）：** 前端、Java、Engine 持久传递输入基线及可编辑范围。范围外改动/新增拒绝，范围外原有缺项仅警告，范围外建议转 DEFER；全文生成仍执行完整规则。接受模型规范化结果为基线前检查原文，防丢失、复制、挪栏、重复次数和同字段顺序变化；标准时间/元数据精确核对。标准表额外列以 `template_extensions.source_table_columns` 保存并导出备注表。

- **F3 控制与硬期限（Q9-C）：** 修复 PATCH 代理和启动立即取消，持久 STOPPING 防迟到状态复活。Windows Job 管理请求/分析子孙进程，默认请求 60 秒、分析 300 秒，无默认整课总时限；暂停不计活动时间，但在途 HTTP 仍受实际经过时间限制。未知结果不自动重发，重启未完成课堂为 INTERRUPTED，不自动恢复付费推理。
- **F3 分析归档：** 实际故障检查发现远端已失败而 Java/页面仍显示旧归档，现将 FAILED/COMPLETED 分析各自追加快照，课堂原 execution/events 不改，失败分析不导入问题池。页面失败后只读刷新，明确重试成功后清除旧错误；失败/未知分析只经用户显式动作重试，正常课堂结束的一次自动分析保留。
- **F1 恢复与进程清理（Q9-A、Q9-C、PDF-D03）：** 整批安全续跑复用已完成项，不自动重做收费未知项；评分与产物 worker 隔离，默认 900 秒硬限，迟到输出不发布，并修复 TaskStore 原子写入的 Windows 长路径问题。PDF 转换器使用 Windows Job 约束子孙，修复快速退出启动器漏清理。
- **开关、历史修复与恢复（Q9-D/E）：** structure/F1/F2/F3/F4 五项新任务开关完成，已准入任务和历史操作继续。V28 保存 F4 准入及请求快照，恢复旧会话只读核对；真实 MySQL 并发、旧库排序规则及关联查询兼容已修复。V26 提供带完整行快照和摘要校验的条件回退，拒绝覆盖后续变更。问题池同步失败恢复、原 Windows 启停故障、隔离备份恢复和现有旧数据升级均已补验。
- **Windows 小范围准备：** 增加本机 Nginx 统一入口、配置检查及按进程身份启停。它仅服务 `127.0.0.1`，本轮未开放互联网。
