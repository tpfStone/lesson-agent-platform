## 已实施内容

### T0 / T1：基线、样例和结构契约

- 保存原始字节基线，补充离线测试入口，Node 固定为 22.19.0，npm 锁文件保持原字节。
- LessonDocument 1.1 增加稳定行 ID、教学列映射和统一正文投影；以表格单元格为权威，教学语义不一致时拒绝保存。
- 1.0 使用冻结的旧派生规则只读校验，独立时间列等历史语义不会被新版规则误判；不改写历史存量。
- 修正 Markdown 分隔行、重复表头、空活动行、转义竖线和换行；保留额外列、未知块和非课堂正文。
- 固化原始 V0 结构 fixture，验证六环节和 `5/12/8/9/4/2` 时长；V1/V2 不强行套用六行。DOCX 检测合并、嵌套表、图片、文本框、页眉页脚等并提示损失；复杂排版不承诺保真。

### T2：版本写入与历史结构

- 统一写入服务将正文、结构、current head、操作幂等记录及来源版本放在同一短事务，保留归属及冲突校验。
- 结构绑定正文 SHA、结构 SHA、投影版本，读取验证绑定，不能因 versionId 相同就复用其他内容的结构。
- 导入先解析/暂存原稿再进入事务，保留原字节和摘要，失败清理未引用暂存文件。
- 缺失结构自动补录默认关闭；显式开启后只做条件插入，不覆盖已验证结构，不把未知原因当作成功恢复。
- 增加历史结构检查及双摘要条件修复，保存旧结构快照/审计，不修改历史正文或 head。

### T3 / T9：F3 材料与恢复

- Java、Runner、F3 DTO 和角色输入贯通时长、教师/学生/评价、额外字段和来源；目标/作业保留为上下文。已验证结构不依赖 F4；兼容路径保留 mixed 和非课堂内容并提示。
- 创建指纹持久化，同键异内容冲突；重启中的课堂明确中断，不自动重演。暂停计入预算，输入队列和并发有上限，超时请求远端结束，未知终态继续对账。
- 对不存在的远端请求持久化取消标记，防止迟到 Runner 再创建，同时释放平台额度。
- 执行/分析/归档状态分离；失败分析可重试，已完成分析可补产物，平台可追加分析修订，执行快照不可变；页面提供状态和重试入口。
- 结果文件原子替换。终态内存清退前先落盘已有分析及结果；写失败保留内存以便重试，避免重新调用模型。默认保留最多 16 个已停止终态运行对象，历史索引仍随会话数增长。

### T4 / T10：F4 修订与并发

- 保存结构和来源绑定，按来源引用修改权威单元格并重建派生字段；拒绝分支保留原文。无法映射的自由改写显式降级，保留未审阅行、表头、额外列、目标及作业。
- 标题归一、编号、时长及空/长标题回退与 Java 对齐；旧版缺少列映射时明确降级。
- 平台校验来源版本和双摘要；同结果重试复用版本，同正文异结构不误去重，过期 head 冲突。
- 短事务认领→事务外模型→短事务校验提交；认领有期限，迟到结果不能覆盖更新，读请求不再等待模型持有写事务。新增 SQLite 结构及认领迁移。

### T5：F2 输入和采用

- 优化输入使用当前验证结构生成 DOCX。best/candidate 使用各自真实制品，教师自由改写明确降级，不冒用旧候选结构；重复采用不同内容冲突。
- 从零生成由服务端读取本人已完成任务的正式结果并采用，记录 job/revision 绑定；清缓存、换浏览器不再由客户端重构不完整正文。
- 补齐 packaging 必需 README，验证 editable 安装，新增 DOCX 契约测试；不声称找回权威仓库中缺失的历史测试。

### T6 / T7：导出、预览和账号状态

- 当前版本 DOCX 从权威结构生成真实可编辑表格，下载目标与选定版本一致。
- 正式 PDF 从同版本规范 DOCX 转换：并发 2、超时 60 秒、独立临时目录、签名检查；未配置转换器时明确不可用。本机未完成 PDF 子项目验收。
- 共享安全结构预览及质量提示；损坏/网络失败明确显示，历史缺失才走兼容正文。版本切换、浏览器返回、A 慢 B 快、导入/优化预览有失效保护。
- 退出/换账号清理私有存储和 Pinia，拒绝旧响应；旧 restore 失败不能清除新登录账号。

### T8：F1 提交、重启和产物

- 平台先保存提交意图/输入，再调用 F1；单项、批次有稳定请求键、指纹和对账，响应丢失可补绑定。

```powershell
java -jar target/Lesoongen-0.0.1-SNAPSHOT.jar --spring.profiles.active=structure-repair --repair-report=structure-repair-report.json
```

该 profile 默认关闭 Flyway、调度和自动补录，要求数据库已迁移，结束自动退出。不会自动把原稿认定为当前版本。

人工复核后准备 JSON 数组 manifest，每项包含 `versionId`、`expectedContentSha256`、`expectedOldRawStructureSha256`（缺失为 null）、`documentPath`、`reason`。documentPath 相对于 manifest，替换结构投影必须等于历史正文。

```powershell
java -jar target/Lesoongen-0.0.1-SNAPSHOT.jar --spring.profiles.active=structure-repair --repair-apply=true --repair-manifest=reviewed-repairs.json --repair-report=after-repair.json
```
