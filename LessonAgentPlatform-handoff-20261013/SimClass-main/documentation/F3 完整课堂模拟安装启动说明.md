# F3 完整课堂模拟安装启动说明

## 1. 环境

建议继续使用当前 `SimClass-main/.venv`。Windows PowerShell：

```powershell
cd "C:\Users\宸洱\Desktop\LLM教案系统\SimClass-main"
& ".\.venv\Scripts\python.exe" -m pip install -r requirements.txt
```

新增正式 API 所需依赖已写入 `requirements.txt`：FastAPI、Pydantic v2、Uvicorn、httpx。

## 2. 配置

```powershell
Copy-Item .env.example .env
```

Mock 功能验收：

```ini
F3_MODEL_MODE=MOCK
F3_STORAGE_ROOT=runtime/f3_sessions
```

真实模型验收：

```ini
API_KEY=你的真实Key
BASE_URL=OpenAI兼容地址
MODEL=真实模型ID
F3_MODEL_MODE=REAL
F3_STORAGE_ROOT=runtime/f3_sessions
```

不要把真实 Key 提交到仓库。

## 3. 启动正式 API

```powershell
& ".\.venv\Scripts\python.exe" -m uvicorn app.api.classroom_api:app --host 127.0.0.1 --port 8003
```

健康检查：

```powershell
Invoke-RestMethod http://127.0.0.1:8003/api/health
```

F3 使用 8003，不占 F4 的 8000。

## 4. 运行原 CLI

原 CLI 保持可用：

```powershell
& ".\.venv\Scripts\python.exe" -m app.main --mock --debug
```

## 5. 全量测试

```powershell
& ".\.venv\Scripts\python.exe" -m pytest -q -rs
```

本交付包在无真实 API 凭据环境下结果：`72 passed, 3 skipped`；3 项 skip 为原项目
`RUN_REAL_LLM_TESTS=true` 才会执行的真实模型验证。

## 6. 真实模型测试

确认 `.env` 已配置后：

```powershell
$env:RUN_REAL_LLM_TESTS="true"
& ".\.venv\Scripts\python.exe" -m pytest tests/test_validation_real.py -v -s
```

然后启动 API，用一份真实教案调用 `POST /api/classroom/sessions`，显式传：

```json
{"modelMode":"REAL"}
```

验收时必须确认返回 `modelMode=REAL` 且 `modelProvider` 不是 `mock`。
