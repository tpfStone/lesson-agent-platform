# F3 接入总平台交接说明

## 1. 总平台应该接什么

总平台只需要对接正式 API，不要把学姐独立静态 Web 搬入总 Vue。

F3 服务地址建议：

```text
http://127.0.0.1:8003
```

创建课堂时由总平台提供：

```text
lessonId
versionId
materials[]
requestKey
modelMode（或由 F3 配置决定）
timeoutSeconds
maxConsecutiveTimeouts
maxEvents
maxWallClockSeconds
```

## 2. materials Adapter

每个教案步骤/章节转为：

```json
{
  "materialId": "稳定步骤ID",
  "title": "环节标题",
  "teachingScript": "该环节实际教学内容",
  "keyPoints": ["要点"],
  "sourceSectionId": "F2/F4 原步骤ID",
  "metadata": {}
}
```

不要只传展示标题；Agent 需要 `teachingScript/keyPoints` 才能进行真实课堂推演。

## 3. 前端状态

总 Vue 只展示 F3 返回的真实状态：

```text
RUNNING / PAUSED / STOPPING / COMPLETED / INTERRUPTED / FAILED
```

不要在前端自己推断“暂停/完成”。如果 worker 异常，F3 会给 `FAILED`；上限或人工结束
给 `INTERRUPTED`。

## 4. 对话/事件展示

统一 Web 应读取：

```text
GET /api/classroom/sessions/{sessionId}/events
```

按 `sequence` 展示；可折叠显示 `managerDecision.reason`。不要只显示 summary，也不要从
旧 `dialogue_history` 拼装无 ID 记录。

## 5. 结果写回

课堂结束后读取：

```text
GET /api/classroom/sessions/{sessionId}/result
```

总平台本地 DB 建议保存：

- `session` 元信息；
- 完整 `events`；
- `statistics/summary`；
- `issues/actionItems`；其中 issues 已在 F3 内完成证据校验、同质问题合并、优先级排序和 Top 5 截断；
- artifact 路径或下载后的本地文件信息。

F3 自己只做运行期文件持久化，不直接写 Lessongen-main 的业务数据库。

## 6. 公共问题层

F3 原生问题类别不要直接改公共枚举。总平台在公共上下文层做映射：

```text
F3 issue
  -> CommonIssue(sourceModule="F3", sourceSessionId=sessionId,
                 sourceVersionId=versionId, evidence=...)
  -> F2/F4 按需读取
```

`resolvedInSimulation=true` 只表示课堂模拟里后续出现回应，不代表教案正文已经修改完成。
F4 应优先消费 F3 最终 `issues[]/actionItems[]`，不要再读取未治理的候选问题做重复修改。

## 7. 任意入口工作流

F3 不依赖固定“F1 -> F2 -> F3 -> F4”顺序。总平台只要当前 lesson/version 有可用
materials 就能直接创建 F3 session；如果 F1/F2/F4 已有上下文，可由公共上下文层附加，
没有则不强制。

## 8. 旧接口迁移

旧：

```text
POST /api/classroom/start
POST /api/classroom/message
GET /api/classroom/{id}/state
```

仍能使用，但新开发应迁移到 `/api/classroom/sessions/...`。旧 `/message` 已变成异步
排队语义，不再假设一个 HTTP 请求就同步得到一轮 Agent 回复。

## 9. 当前边界

REAL 完整课堂已由用户本机 DeepSeek `deepseek-flash` 完成整链验收：课堂正常
`MANAGER_END_CLASS`，覆盖 teacher / inquisitive_mind / note_taker 三类角色，并生成真实
issues/actionItems/artifacts。总平台接入和数据库写回仍不在本 F3 专项包内修改。
