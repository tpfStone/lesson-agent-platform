# 工程测试参考：数据安全与隐私 / Data Security and Privacy

## 中文

- 个人信息可能单独识别个人，也可能与其他信息结合后识别个人。
- 风险分析至少考虑收集范围、访问权限、传输、保存、共享和删除。
- 常见保护措施包括最小化收集、唯一且强的密码、多因素验证、谨慎授权、备份与及时报告异常。
- 课堂案例应使用虚构信息，不要求学生公开真实账号、密码、住址或联系方式。

## English

- Personal information may identify a person directly or when combined with other data.
- Risk analysis should consider collection, access, transmission, storage, sharing, and deletion.
- Protections include data minimization, unique strong passwords, multi-factor authentication, careful permissions, backups, and prompt incident reporting.
- Classroom scenarios must use fictional data and must not ask students to disclose real credentials, addresses, or contact details.
