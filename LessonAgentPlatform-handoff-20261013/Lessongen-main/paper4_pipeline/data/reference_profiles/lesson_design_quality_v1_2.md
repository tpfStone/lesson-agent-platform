# 教案质量参考画像 v1.2

本画像从用户提供的英语教案样例中提炼“可迁移的质量信号”，不是模板全文，也不是权威评分标准。

## 值得保留

- 前置分析完整：课程依据、内容分析、学情、素养目标、重点难点和方法资源形成连续逻辑。
- 教学过程明确区分教师推进、学生任务与评价重点，信息密度足以支持试教。
- 教案包含板书设计和反思入口，而不仅是活动清单。
- 版面采用 A4、黑白灰、连续细线表格与清晰分区，便于打印、批注和归档。

## 必须超越

- 每个核心环节都要给出真实问题、任务材料或例题、预期学生产出、成功标准和教师调控分支；不能只写“引导、讨论、练习”。
- 学科内容、学习任务和评价证据要一一对应；结构齐全但没有可直接使用的内容不算高质量。
- 活动必须服务于清晰的认知转变，情境热闹或语言华丽不能替代学科深度。
- 输入未提供教材原文、课标条款或答案依据时，必须显式标注待核验，不得虚构页码、条款和出处。
- 课后反思只能写观察点或留白提示，生成前不得声称学生已经取得某种效果。

## 不得模仿

- 不复制样例中的学校名称、校徽、学科网广告、二维码、页脚版权或具体课文表达。
- 不采用过窄评价列、强制两端对齐英文、大面积空白反思页或多余广告页。
- 不把样例当成绝对优质答案；其中笼统活动、语言错误和不可核验内容都应被批判性修正。

## 成稿最低可用信号

一份面向“精品/展示”用途的教案至少应有：一句教学设计主张、一个驱动问题、清晰学习轨迹、可观察目标、逐环节学生作品、成功标准、真实问题链与追问、至少一份可直接使用的教学材料、形成性评价闭环、基础支架与拓展任务、板书结构以及课后观察点。
