# 规格质量检查清单

## 产品边界

- [x] MVP 只有“生成教案”和“上传 DOCX 优化教案”两个核心功能。
- [x] 明确排除登录、完整 RAG、Paper#3、Word 在线编辑、多机队列。
- [x] 明确内部 Judge 分数不是正式教学成效结论。
- [x] 开放问题已有不阻塞开发的默认决策。

## 架构与职责

- [x] Vue 只访问 Spring Boot，不接触 Python、Key 和磁盘路径。
- [x] Spring Boot 负责公开 API、任务状态、MySQL、权限边界和下载。
- [x] Python 复用现有 `PipelineService` 与 LangGraph，不在 Java 重写 Agent。
- [x] MySQL 保存元数据，DOCX/trace 放文件存储。
- [x] 长任务异步运行，创建接口返回 202。
- [x] 测试 stub 与生产实现的边界明确，禁止生产 Mock Agent。

## Word 优化真实性

- [x] 未声称现有 pipeline 能直接读取任意 Word。
- [x] 定义安全检查、内容抽取、结构规范化、Pydantic 校验和失败策略。
- [x] 规范化器被定义为输入适配器，而非第四个 Critic。
- [x] 用户确认的科目/年级/课题/课时优先，禁止模型补造课标出处。
- [x] 明确输出使用标准模板，不承诺保留原 Word 样式。

## 契约与数据

- [x] 公开 API 的请求、状态、结果、SSE、下载和 Problem Details 已定义。
- [x] 内部 API 的幂等、状态、事件、结果、产物、超时和重试已定义。
- [x] 八维字段与现有 `RubricScores` 一致。
- [x] 最佳版本与最后版本分别保存。
- [x] stop reason、错误码、用量与产物哈希可追溯。
- [x] 状态机只允许向前迁移，终态不可覆盖。

## 安全与隐私

- [x] 上传限制包含类型、magic、OOXML、压缩数量/大小/比例、Zip Slip、宏、OLE、外部关系和加密包。
- [x] 下载只能使用 artifact ID 并验证任务归属、路径与哈希。
- [x] 日志/SSE/错误不泄露 Key、Prompt 全文、思维链、用户全文和绝对路径。
- [x] 原 Word 只读保留，优化结果不覆盖输入。
- [x] `.env`、storage、artifacts、日志和真实教案不得进入 Git。

## 用户体验

- [x] 表单字段分必填、推荐和高级选项，不要求用户编辑 JSON。
- [x] 进度使用真实阶段与轮次，SSE 可回放且有轮询退化。
- [x] 失败、待人工复核与成功三种结果语义分开。
- [x] 动画服务于反馈，支持 reduced-motion，不用假进度掩盖等待。
- [x] 桌面、平板、移动端和键盘操作均有验收要求。

## 可实施性

- [x] 数据表、索引、Flyway、目录和类职责已指定。
- [x] 任务拆成可测试的阶段和垂直切片。
- [x] 每个阶段有退出条件，关键任务标明依赖顺序。
- [x] 自动测试不消耗 DeepSeek；真实验收固定为一条生成和一条优化。
- [x] Quickstart 明确标注为目标态，避免误导当前即可运行。

## 进入编码前只需确认

- [x] Spring Boot 4.1.1 与当前依赖仓库已在本机通过 Wrapper 解析、测试和打包。
- [x] MySQL 8.0.44、默认 3306 端口及本地 `lesoongen` 用户配置已验证。
- [x] 5 份脱敏 DOCX 已验收；4 份通过，1 份因外部关系被明确拒绝。
- [x] MVP 保留临时产品名“灵犀教案”。
